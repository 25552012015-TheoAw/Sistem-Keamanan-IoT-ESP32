## 📝 Deskripsi Proyek
Proyek ini merupakan sistem keamanan rumah cerdas berbasis Internet of Things (IoT). Sistem ini menggunakan **Sensor PIR** untuk mendeteksi gerakan manusia. Ketika gerakan terdeteksi, **ESP32** akan secara otomatis mengaktifkan **Buzzer** dan **LED** sebagai alarm lokal, serta mengirimkan notifikasi *real-time* ke smartphone melalui platform **Blynk**.

## 🛠️ Daftar Komponen
| Komponen | Fungsi |
| :--- | :--- |
| **ESP32** | Mikrokontroler utama & konektivitas WiFi |
| **Sensor PIR** | Mendeteksi gerakan di area sekitar |
| **Buzzer** | Output suara alarm |
| **LED** | Indikator visual keamanan |

## 🚀 Fitur Utama
* ✅ Deteksi gerakan akurat menggunakan sensor PIR.
* ✅ Notifikasi *real-time* ke aplikasi Blynk.
* ✅ Alarm lokal (Buzzer & LED) sebagai respon cepat.
* ✅ Monitoring status sistem via dashboard Blynk.
